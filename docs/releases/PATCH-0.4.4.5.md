# KINOSIS 0.4.4.5

P0 + P1 core UX/performance patch.

- Search: instant local + 250 ms remote merge, people/movie grouping, exact ranking, keyboard navigation, TMDB-id canonical identity.
- Detail: revised film hierarchy, primary personal state, Where to Watch immediately after hero, 6–8 cast, related films.
- APIs: conditional theatrical validation, static/availability cache split, centralized KR locale.
- Arthouse: Director Archive and Editorial Curation are separate data models; collection-card index and editorial chapters.
- Library: retrieval-first toolbar/filtering, simplified collection navigation.
- MY: ARIA tabs, `기록` semantics, lean overview.
- Export: KINOSIS JSON + Letterboxd-compatible Diary/Watchlist CSV.
- Sharing: movie/curation OG preview endpoint.
- CSS: consolidated stylesheet pass; Search/Detail extracted from `app.js`.

Not included by design: country selector, Social, AI recommendations, new Discover shelves, Year in Review.
