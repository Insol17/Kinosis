# KINOSIS MVP 0.4.4

## Product statement

KINOSIS helps a user discover a film, find where it is available, record the viewing, manage a personal library, and look back on that film life across devices.

## Top-level IA

- **DISCOVER** — general discovery and light personalization.
- **ARTHOUSE** — auteur, classic, independent and art-cinema exploration.
- **LIBRARY** — dense retrieval, filtering, Watchlist and Collections.
- **MY** — profile overview, Reviews, Stats and Settings.
- **SEARCH** — global action, not a destination.
- **MOVIE DETAIL** — shareable public film information plus the signed-in user's relationship with the film.

## Account policy

Guests may browse Discover, Arthouse, Search and movie details. Library/MY and personal mutations require sign-in so personal data always has an account-backed synchronization model.

## Core loop

```text
Discover/Search
→ Film Detail
→ Watchlist / availability
→ View film
→ Log / Review
→ Library + MY
→ recommendation / rediscovery
```

## Review model

`ViewingLog` is the source for chronological film-life history. A second viewing creates a second log and is shown as a rewatch. Logs are editable and deletable. The latest rating becomes the current UserFilm rating without rewriting earlier historical ratings.

## Arthouse

Arthouse candidates are generated by deterministic metadata/canon/director signals. 0.4.4 intentionally avoids a user-facing numeric art score. The weekly updater expands the candidate pool. Editorial Curation is file-authored from the repository; no admin account or editor UI ships in this patch.

## Personalization

For You requires enough rated history. It uses high-rated films as seeds, retrieves live TMDB recommendations/similarity, excludes already-owned records where appropriate, and gives a coarse explanation of why the shelf exists.
