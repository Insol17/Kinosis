# KINOSIS 0.4.4 — UX rules

## 1. One film, three layers

- **Movie:** public TMDB-backed work.
- **UserFilm:** current relationship — Watchlist, Favorite, current rating, saved state.
- **ViewingLog:** one actual viewing event — date, per-viewing rating, review, rewatch.

A rewatch creates another ViewingLog; it does not erase the first viewing. The current Library rating follows the latest viewing that contains a rating, while Reviews preserves historical ratings.

## 2. MY is a personal overview, not a feature directory

MY exposes only:
- Overview
- Reviews
- Stats
- Settings

Calendar is a visualization inside Overview. Diary and Reviews are one viewing-history concept, so they are not separate tabs.

## 3. A calendar date is a container

A date may have 0..N viewing logs. A date cell is only a compact summary; opening the date reveals every film and provides a route to edit the exact viewing event.

## 4. Discover stays finite

Signed-in Discover prioritizes:
1. Featured
2. For You (only when enough history exists)
3. Now in Theatres
4. Available on My Services
5. one broad discovery shelf such as Trending / Highly Rated

Do not keep adding a new permanent shelf for every feature.

## 5. Arthouse is denser

Arthouse is an editorial/content destination, not a theme. Its horizontal cards are intentionally smaller than general Discover cards. Short result sets keep their normal poster width instead of expanding to fill the row.

## 6. Recommendations are explainable

0.4.4 uses explicit user-history signals to choose seed films, then live TMDB recommendation/similarity candidates. It does not describe this as AI personalization. If recommendation quality later warrants embeddings, the candidate/rerank interface can be replaced without changing the UX promise.

## 7. Library is derived from intent

Watchlist, Log, Favorite and Collection actions all ensure that a movie exists in the Library. Users should not have to understand storage mechanics to preserve a film.

## 8. Portability is a product feature

KINOSIS JSON export remains available. Letterboxd CSV import reduces switching cost and preserves an exit route from other film trackers.
