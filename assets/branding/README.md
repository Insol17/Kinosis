# TMDB brand asset

`tmdb-logo.svg` is the official TMDB square mark used only for required API attribution in KINOSIS's About / Credits surface.

- Original TMDB asset source documented by Wikimedia Commons: `https://www.themoviedb.org/assets/2/v4/logos/v2/blue_square_2-d537fb228cf3ded904ef09b136fe3fec72548ebc1fea3fbbd1ad9e36364db38b.svg`
- Retrieval mirror used for this repository copy: Wikimedia Commons, `File:Tmdb.new.logo.svg`
- The logo must not be recolored, distorted, flipped, rotated, or made more prominent than KINOSIS branding.
- Required product notice is rendered next to it in the About / Credits dialog.

Before changing this asset, re-check TMDB's current Logos & Attribution guidance.
