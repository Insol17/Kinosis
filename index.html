데이터 출처

TMDB

영화 제목, 개봉정보, 감독/장르, 평점, 포스터 및 배경 이미지의 기본 소스로 사용합니다. Netlify 배포에서는 서버리스 Function이 TMDB 전체 영화 검색과 상세정보 조회를 중계합니다.

This product uses the TMDB API but is not endorsed or certified by TMDB.

JustWatch via TMDB

대한민국 지역의 스트리밍/무료/대여/구매 제공처 정보는 TMDB Watch Providers가 제공하는 JustWatch 데이터를 사용합니다.

Collectio / 콜렉티오

MY → Subscriptions에서 구독 상태를 수동으로 관리할 수 있습니다. 현재 KINOSIS는 콜렉티오 작품 availability를 자동 수집하거나 크롤링하지 않습니다.

ART MODE

예술영화를 단일 장르로 간주하지 않습니다. 정성일의 한국영상자료원 「시네필 안내서」 같은 캐논 목록을 시드로 삼고, 감독·키워드·제작/배급 메타데이터를 가중해 KINOSIS 내부에서 설명 가능한 boolean 분류를 계산합니다. 숫자 점수는 내부 판정에만 사용합니다.

Supabase

로그인 사용자 Library/MY 데이터의 기기 간 동기화에 사용합니다. 브라우저에는 Publishable Key만 사용하며 RLS로 사용자별 데이터를 격리합니다.

현재 MVP 범위

KOBIS·KMDb는 한국 극장/한국영화 데이터 보강 후보입니다. ART MODE 시드 참고는 KMDb 공개 「시네필 안내서」를 사용하지만 작품 설명문을 복제하지 않습니다.
